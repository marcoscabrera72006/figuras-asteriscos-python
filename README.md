# Figuras con asteriscos en Python

Clase interactiva para aprender a dibujar figuras de asteriscos en la consola con Python: cuadrados, pirámides, rombos, relojes de arena, mariposas y más.

**Abrir la clase:** https://marcoscabrera72006.github.io/figuras-asteriscos-python/

## Qué hay

- `index.html`: la clase completa. Se abre en cualquier navegador, sin instalar nada.
- `figuras/`: 11 figuras resueltas, cada una de dos formas (contando por fila y casilla por casilla).
- `ejercicios/`: las soluciones de los 6 ejercicios de la clase.
- `actividad13/`: las 5 figuras de la Actividad 13: letra M, triángulo invertido, rombo sólido, cuadrado con diagonales y estrella con cruz.

## Cómo ejecutar un programa

Abre una terminal en esta carpeta y escribe, por ejemplo:

```
python figuras/10_mariposa.py
```

El programa te pide el tamaño n y dibuja la figura.
