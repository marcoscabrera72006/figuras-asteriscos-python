Lo básico de Python que necesitas

La consola es como una hoja cuadriculada. Python escribe de izquierda a derecha y de arriba abajo, como tú en el cuaderno, pero no puede volver atrás. Por eso, para dibujar, decides fila por fila qué va en cada casilla: un espacio o un asterisco. Con estas cuatro piezas alcanza.

print y end=""

Normalmente print termina con un salto de línea. Con end="" le dices que no salte, y lo siguiente queda al lado. Un print() vacío solo salta de línea.

Código
print("*", end="")
print("*", end="")
print("*", end="")
print()
print("*")
print("*")
Sale en la consola

Multiplicar y sumar textos

Un texto por un número lo repite. Con + pegas textos. Así armas una fila completa en una sola línea de código.

Código
print("*" * 5)
print(" " * 3 + "*" * 2)
print("*" + " " * 3 + "*")
Sale en la consola

range: los números que recorre el for

El segundo número nunca se incluye. Con un tercer número negativo, cuenta hacia atrás.

Escribesi toma los valores
range(4)0, 1, 2, 3
range(1, 5)1, 2, 3, 4
range(1, n + 1)1, 2, …, n
range(2, 5)2, 3, 4
range(4, 0, -1)4, 3, 2, 1
range(0)ninguno: el for no da vueltas

Un for dentro de otro

El for de afuera recorre las filas. El de adentro escribe lo que va dentro de cada fila. Funciona como un reloj: el minutero (el de adentro) da la vuelta completa por cada paso del horario (el de afuera).

Código
for i in range(1, 4):
    for j in range(1, 6):
        print("*", end="")
    print()
Sale en la consola

Fíjate en la sangría: el print() está fuera del for de adentro, así que corre una vez por fila, al terminarla.

Cómo sacar la fórmula

      
Mira cuánto cambia la columna de una fila a la siguiente. Ese cambio es el número que multiplica a la i. Después ajustas con la fila 1.

      

        

          Asteriscos: 1, 3, 5, 7
          Suben de 2 en 2, así que empieza con 2 * i. En la fila 1 da 2, pero hay 1: le restas 1.
          Fórmula: 2 * i - 1. Compruébala en la fila 3: 2 · 3 − 1 = 5 ✓
        

        

          Espacios: 3, 2, 1, 0
          Bajan de 1 en 1, así que lleva - i. En la fila 1 hay 3, y 3 = 4 − 1, donde 4 es n.
          Fórmula: n - i. Compruébala en la fila 3: 4 − 3 = 1 ✓

Cuadrado lleno
Método 1figuras/01_cuadrado.py

      
Todas las filas son iguales: n asteriscos. Es el mejor ejemplo para entender un for dentro de otro.

      

      

        
for i in range(1, n + 1):      # una vuelta por cada fila
    for j in range(n):         # n asteriscos en esta fila
        print("*", end="")     # end="" -> no salta de línea
    print()                    # fin de la fila: ahora sí saltamos
for i in range(1, n + 1):
    print("*" * n)             # "*" * 4 da "****"

      

    


    

      
Cuadrado hueco
Método 2figuras/02_cuadrado_hueco.py

      
Solo el borde lleva asteriscos. Casilla por casilla: hay asterisco si estás en la primera o la última fila, o en la primera o la última columna.

      

      

        
for i in range(1, n + 1):          # i = fila
    for j in range(1, n + 1):      # j = columna
        if i == 1 or i == n or j == 1 or j == n:   # ¿estoy en el borde?
            print("*", end="")
        else:
            print(" ", end="")
    print()
for i in range(1, n + 1):
    if i == 1 or i == n:                    # primera y última fila: llenas
        print("*" * n)
    else:                                   # filas del medio
        print("*" + " " * (n - 2) + "*")    # borde + hueco + borde

    


    

      
Triángulo rectángulo
Método 1figuras/03_triangulo.py

      
La fila i lleva i asteriscos. Por eso el for de adentro usa range(i): en cada fila da una vuelta más.

      

      

        
for i in range(1, n + 1):      # i = 1, 2, 3, ..., n
    for j in range(i):         # en la fila i van i asteriscos
        print("*", end="")
    print()
for i in range(1, n + 1):
    print("*" * i)

      

    


    

      
Triángulo invertido
Método 1figuras/04_triangulo_invertido.py

      
El mismo triángulo con i contando hacia atrás: range(n, 0, -1) da n, n − 1, …, 1. Mira la columna i de la tabla.

      

      

        
for i in range(n, 0, -1):      # i = n, n-1, ..., 1 (cuenta hacia atrás)
    for j in range(i):         # i asteriscos
        print("*", end="")
    print()
for i in range(n, 0, -1):
    print("*" * i)

      

    


    

      
Triángulo alineado a la derecha
Método 1figuras/05_triangulo_derecha.py

      
Antes de los asteriscos van n − i espacios. Así todas las filas terminan en la misma columna.

      

      

        
for i in range(1, n + 1):
    for j in range(n - i):     # primero los espacios: n - i
        print(" ", end="")
    for j in range(i):         # después los asteriscos: i
        print("*", end="")
    print()
for i in range(1, n + 1):
    print(" " * (n - i) + "*" * i)    # el + pega los dos textos

      

    


    

      
Pirámide
Método 1figuras/06_piramide.py

      
Los espacios bajan de 1 en 1 y los asteriscos suben de 2 en 2. Es la base del rombo y del reloj de arena, así que vale la pena entenderla bien.

      

      

        
for i in range(1, n + 1):        # i = número de fila: 1, 2, ..., n
    for j in range(n - i):       # primero, n - i espacios
        print(" ", end="")
    for j in range(2 * i - 1):   # después, 2*i - 1 asteriscos
        print("*", end="")
    print()                      # fin de la fila
for i in range(1, n + 1):
    print(" " * (n - i) + "*" * (2 * i - 1))

      

    


    

      
Rombo
Método 1Dos partesfiguras/07_rombo.py

      
Una pirámide y debajo la misma pirámide al revés. Las fórmulas no cambian, solo cambia por dónde va i. Abajo empieza en n − 1 para no repetir la fila del medio.

      

      

        
# Parte de arriba: una pirámide (i = 1, 2, ..., n)
for i in range(1, n + 1):
    for j in range(n - i):
        print(" ", end="")
    for j in range(2 * i - 1):
        print("*", end="")
    print()
# Parte de abajo: la misma pirámide al revés (i = n-1, ..., 1)
for i in range(n - 1, 0, -1):
    for j in range(n - i):
        print(" ", end="")
    for j in range(2 * i - 1):
        print("*", end="")
    print()
for i in range(1, n + 1):
    print(" " * (n - i) + "*" * (2 * i - 1))
for i in range(n - 1, 0, -1):
    print(" " * (n - i) + "*" * (2 * i - 1))

      

    


    

      
Reloj de arena
Método 1Dos partesfiguras/08_reloj_de_arena.py

      
El rombo al revés: arriba la pirámide invertida (i de n a 1) y abajo la pirámide normal (i de 2 a n). Abajo empieza en 2 para no repetir la cintura.

      

      

        
# Parte de arriba: pirámide invertida (i = n, n-1, ..., 1)
for i in range(n, 0, -1):
    for j in range(n - i):
        print(" ", end="")
    for j in range(2 * i - 1):
        print("*", end="")
    print()
# Parte de abajo: pirámide normal (i = 2, 3, ..., n)
for i in range(2, n + 1):
    for j in range(n - i):
        print(" ", end="")
    for j in range(2 * i - 1):
        print("*", end="")
    print()
for i in range(n, 0, -1):
    print(" " * (n - i) + "*" * (2 * i - 1))
for i in range(2, n + 1):
    print(" " * (n - i) + "*" * (2 * i - 1))

      

    


    

      
Letra X
Método 2figuras/09_x.py

      
Dos diagonales. En la diagonal \ la columna es igual a la fila (j == i). En la diagonal / se cumple j == n − i + 1. Con n impar la X tiene centro.

      

      

        
for i in range(1, n + 1):              # i = fila
    for j in range(1, n + 1):          # j = columna
        if j == i or j == n - i + 1:   # ¿estoy en alguna diagonal?
            print("*", end="")
        else:
            print(" ", end="")
    print()

    


    

      
Mariposa
Método 1Dos partesfiguras/10_mariposa.py

      
Cada fila tiene tres grupos: ala izquierda (i asteriscos), hueco (2 · (n − i) espacios) y ala derecha (i asteriscos). Arriba i va de 1 a n y abajo de n − 1 a 1, igual que en el rombo. Si tu profe la quiere con dos filas llenas en el centro, cambia range(n - 1, 0, -1) por range(n, 0, -1).

      

      

        
# Parte de arriba (i = 1, 2, ..., n)
for i in range(1, n + 1):
    for j in range(i):                 # ala izquierda
        print("*", end="")
    for j in range(2 * (n - i)):       # hueco del centro
        print(" ", end="")
    for j in range(i):                 # ala derecha
        print("*", end="")
    print()
# Parte de abajo (i = n-1, ..., 1): lo mismo al revés
for i in range(n - 1, 0, -1):
    for j in range(i):
        print("*", end="")
    for j in range(2 * (n - i)):
        print(" ", end="")
    for j in range(i):
        print("*", end="")
    print()
for i in range(1, n + 1):
    print("*" * i + " " * (2 * (n - i)) + "*" * i)
for i in range(n - 1, 0, -1):
    print("*" * i + " " * (2 * (n - i)) + "*" * i)

      

    


    

      
Pirámide hueca
Método 1+ Método 2figuras/11_piramide_hueca.py

      
Combina los dos métodos. Los espacios de la izquierda se cuentan (n − i). El resto de la fila mide 2 · i − 1 y ahí decides casilla por casilla: asterisco en los dos bordes y en toda la última fila.

      

      

        
for i in range(1, n + 1):
    for j in range(n - i):                       # espacios de la izquierda
        print(" ", end="")
    for j in range(1, 2 * i):                    # j = 1, 2, ..., 2*i - 1
        if j == 1 or j == 2 * i - 1 or i == n:   # borde o base
            print("*", end="")
        else:
            print(" ", end="")
    print()
for i in range(1, n + 1):
    if i == 1:
        print(" " * (n - 1) + "*")                              # la punta
    elif i == n:
        print("*" * (2 * n - 1))                                # la base
    else:
        print(" " * (n - i) + "*" + " " * (2 * i - 3) + "*")    # borde, hueco, borde

En el examen: cómo atacar cualquier figura

      
Si te piden una figura que nunca viste, sigue estos pasos en orden. Casi siempre es una combinación de cosas que ya conoces.

    

  

  

    
    
      
  1. Dibuja la figura en papel con un n pequeño (4 o 5) y numera las filas.
    2. 
      
  2. Elige el método. Si cada fila son grupos seguidos de espacios y asteriscos, usa el Método 1. Si tiene huecos, bordes o diagonales, usa el Método 2, o combina los dos como en la pirámide hueca.
    3. 
      
  3. Si la figura crece y luego decrece (o al revés), pártela en dos: arriba y abajo. Casi siempre la parte de abajo es la de arriba con el range al revés.
    4. 
      
  4. Haz la tabla y saca las fórmulas. Compruébalas con dos filas distintas.
    5. 
      
  5. Escribe el código: un for para las filas y, dentro, lo que va en cada fila. No olvides el print() al final de cada fila.
    6. 
      
  6. Pruébalo en papel con n = 1 y n = 2. Ahí es donde más se rompen las figuras.

Los errores que más se cometen

  

    

      
Olvidar end=""

      
Cada asterisco sale en su propia línea, y la figura queda como una columna.

      
print("*")

      
print("*", end="")

    

    

      
El print() con la sangría equivocada

      
Dentro del for de adentro, salta de línea después de cada asterisco. Fuera de los dos for, todo sale en una sola línea. Va dentro del for de filas y fuera del de columnas.

      
for i in range(1, n + 1):
    for j in range(i):
        print("*", end="")
    print()

    

    

      
Empezar en 0 sin darte cuenta

      
range(n) da 0, 1, …, n − 1. Con fórmulas como 2 · i − 1, la primera fila da −1 y no sale nada.

      
for i in range(n):

      
for i in range(1, n + 1):

    

    

      
Contar hacia atrás mal

      
El segundo número del range no se incluye, tampoco cuando cuentas hacia atrás. Para llegar hasta 1, el tope es 0.

      
range(n, 1, -1)    # n, …, 2 (se salta el 1)

      
range(n, 0, -1)    # n, …, 1

    

    

      
input() sin int()

      
input() siempre devuelve texto, y range("5") da error. Conviértelo a número.

      
n = input("Tamaño: ")

      
n = int(input("Tamaño: "))

    

    

      
Repetir la fila del medio

      
En el rombo, el reloj de arena y la mariposa, la segunda parte empieza un paso después. Si no, la fila del centro sale dos veces.

      
for i in range(n, 0, -1):      # rombo, abajo

      
for i in range(n - 1, 0, -1):  # rombo, abajo

    

    

      
Dividir con /

      
En Python, / da un número con decimales, y " " * 2.0 es un error. Para dividir sin decimales usa //.

      
" " * (n / 2)

      
" " * (n // 2)

    

    

      
Asteriscos con espacio

      
Algunos profes piden * * * en vez de ***. Se arregla en un solo lugar: imprime "* " en vez de "*", y los espacios de la izquierda también se duplican.

      
print("* ", end="")

Cómo atacar una figura nueva

          
El camino que seguiste con estas cinco sirve para cualquier figura hecha de líneas.

        

        

          
    
            
  1. Dibújala en papel cuadriculado con un n pequeño y numera las filas (i) y las columnas (j).
    2. 
            
  2. Divídela en líneas: bordes, diagonales, centro…
    3. 
            
  3. Escribe una condición para cada línea. Casi siempre son i == 1, i == n, j == 1, j == n, j == i, j == n - i + 1 o i == centro.

  4. Si una línea solo va en una parte, como la V de la M, añádele un and con su límite, entre paréntesis.

  5. Junta todo con or y pruébalo con n = 5 o n = 7 antes de darlo por bueno.

Errores típicos en estas figuras

            

              
Olvidar los paréntesis
v = i <= centro and j == i or j == n - i + 1
v = i <= centro and (j == i or j == n - i + 1)
Python hace el and antes que el or.

              
La diagonal / sin el + 1
j == n - i
j == n - i + 1
Con n - i, la fila 1 empezaría en la columna n − 1.

              
Llegar hasta n en el triángulo
for j in range(1, n + 1):
for j in range(1, ancho + 1):
Cada fila del triángulo tiene su propio largo.

              
Repetir la fila del medio del rombo
for i in range(n, 0, -1):
for i in range(n - 1, 0, -1):
La mitad de abajo empieza en n − 1.
